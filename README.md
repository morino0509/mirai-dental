# みらい歯科クリニック

東京都品川区にある架空の歯科医院「みらい歯科クリニック」のWebサイトです。

「やさしい治療を、ていねいに。」をコンセプトに、患者さま一人ひとりに寄り添い、安心して通える歯科医院をイメージして制作しました。

## プロジェクト概要

- **制作目的**：ポートフォリオ用の自主制作
- **制作期間**：約2.5か月
- **担当範囲**：企画・デザイン・コーディング
- **制作形態**：架空の歯科医院のWebサイト

## 使用技術

- HTML
- CSS
- JavaScript
- jQuery
- Slick

## サイト構成

- 当院について
- 診察内容
- 医師紹介
- アクセス
- お知らせ

## 制作の背景・目的

歯科医院に対して「少し緊張する」「なんとなく苦手」と感じる方にも、安心して来院してもらえるようなWebサイトを目指しました。

医院の特徴や診療方針を具体的に設定したうえで、ターゲットとなる患者さまに与えたい印象を整理し、コンセプトに沿ったデザインと情報設計を行いました。

## 制作工程

以下の流れで制作を進めました。

1. **コンセプト設計**：医院の特徴や診療方針、ターゲットとなる患者さまを具体化
2. **情報設計**：掲載する情報を整理し、ページ構成やコンテンツの優先順位を決定
3. **ワイヤーフレーム作成**：各ページのレイアウトや情報配置を設計
4. **デザイン制作**：Figmaでデザインカンプを作成し、色使いや写真、余白などを調整
5. **コーディング**：デザインカンプをもとにHTML・CSS・JavaScriptで実装
6. **動作確認・調整**：レスポンシブ対応や各種アニメーション、表示崩れなどを確認・修正

## デザイン・情報設計の工夫

**1. コンセプトを軸にしたデザイン**

「やさしい治療を、ていねいに。」というコンセプトをもとに、清潔感や安心感、親しみやすさが伝わるデザインを意識しました。

色使いや写真の選定、余白の取り方など、サイト全体で統一感を持たせることで、医院のイメージが一貫して伝わるように工夫しました。

**2. 患者さま目線の情報設計**

初めて来院する方が必要な情報を迷わず確認できるよう、診療内容・医師紹介・アクセス・お知らせなどをページごとに整理しました。

また、予約やお問い合わせへの導線を設け、必要な情報にスムーズにアクセスできる構成を意識しました。

**3. レスポンシブデザイン**

PC・スマートフォンそれぞれの画面サイズに合わせてレイアウトを調整しました。

スマートフォンではナビゲーションやボタンの配置、コンテンツの見せ方を変更し、限られた画面サイズでも操作しやすいように工夫しました。

## 実装・技術的な工夫

**1. Slickを使用したスライダー**

ファーストビューでは、医院の内観写真をフェード切り替えで表示し、ゆったりとした印象を演出しました。

また、複数の画像が流れるスライダーを実装し、サイトに動きと視覚的な変化を加えました。

**2. レスポンシブに対応したスライダー**

診療内容のカード一覧は、PCでは一覧表示、スマートフォンではSlickを使用したスライダーに切り替えるよう実装しました。

画面幅に応じてSlickの初期化・解除を行い、デバイスごとに適した表示方法になるよう工夫しました。

**3. Intersection Observerを使用したスクロールアニメーション**

Intersection Observerを使用し、コンテンツが画面内に入ったタイミングでフェードインするアニメーションを実装しました。

スクロールに合わせて自然にコンテンツが表示されるようにし、閲覧時の視覚的な変化を加えました。

**4. お知らせのカテゴリー絞り込み**

JavaScriptを使用し、お知らせをカテゴリーごとに絞り込める機能を実装しました。

PCではボタン、スマートフォンではプルダウンを使用し、デバイスに応じて操作方法を切り替えています。

**5. お知らせの開閉アニメーション**

Web Animations APIを使用し、お知らせの詳細を開閉する際に高さと透明度を変化させるアニメーションを実装しました。

また、アニメーション中の連続操作を防ぐ処理も追加しました。

**6. ローディングアニメーション**

ページ読み込み後、ローディング画面をフェードアウトさせてからメインビジュアルを表示する演出を実装しました。
